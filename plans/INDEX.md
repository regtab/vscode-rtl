# Планы

Указатель по каталогу `plans/`: один план — одна крупная работа, самый свежий
сверху. Статус и результат каждой работы — в шапке и в разделе «Результат»
самого плана.

- [PYREGTAB_051_SYNC.md](PYREGTAB_051_SYNC.md) — синк с pyRegTab 0.5.1:
  `ANCH(n)`/`REC(n)` переставляет сам атрибут (имя вместе со значениями), пин
  ядра поднят до `v0.5.1`, перегенерирован hover-словарь, покрыта связка
  `AVP` + `ANCH(n)` в preview. **В РАБОТЕ** (2026-08-26).
- [PYREGTAB_050_SYNC.md](PYREGTAB_050_SYNC.md) — синк с pyRegTab 0.5.0: переход
  с плавающей зависимости на git-пин по релизному тегу, видимые пустые элементы
  в match-preview, обновление устаревших пинов и документации.
  **ВЫПОЛНЕН** (0.8.8, 2026-08-26; публикация не запускалась).
- [VSCODE_RTL_PLUGIN_PLAN.md](VSCODE_RTL_PLUGIN_PLAN.md) — дорожная карта
  расширения по фазам (0: перенос подсветки и публикация → 1: сниппеты и тесты
  грамматики → 2: LSP-диагностика → 3: языковые фичи → 4: превью матчинга).
  Опорный документ: изменение архитектурного решения = правка этого плана.
