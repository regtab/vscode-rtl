# Fixture provenance

The `.rtl` files were copied without modification from the pyRegTab conformance corpus
(`pyregtab/conformance/`). Corpus version (its `VERSION` file):

```
generated: 2026-08-26
sources: RtlTask001..150 + curated extras
```

| File | Source | Coverage |
|---|---|---|
| `illustrative.rtl` | `positive/` | Basic AVP/REC, compound content |
| `task_001.rtl` | `positive/` | Quantifiers `{n}`/`+`, `ST*->REC` |
| `task_002.rtl` | `positive/` | Conditional cell, `NORM`, `REC(n)` |
| `task_009.rtl` | `positive/` | `REPL` extractor, subrow `{…}`, `BLANK` |
| `task_016.rtl` | `positive/` | `JOIN`, conjunction `&`, `STR` |
| `task_035.rtl` | `positive/` | Contains `~`, negation `!~`, `REPL` |
| `task_068.rtl` | `positive/` | Tags `#'…'`, cardinality `*` |
| `task_107.rtl` | `positive/` | Fragments `$V`, `FILL`, positional `LT` |
| `task_116.rtl` | `positive/` | Fragments, `PREFIX`, range `R1..3` |
| `ext_unbound_cell.rtl` | `negative/` | `EXT('…')` tokenization (semantically invalid — for phase 2 LSP tests; highlighting only here) |
| `settings_unknown.rtl` | `negative/` | `<…>` settings tokenization |
| `anch_named_attrs.rtl` | `semantic/` | `<ANCH(n)>` setting, `COL->AVP`, named schema |
| `anch_named_inline_delim.rtl` | `semantic/` | Inline `REC(n)` within a delimited specification `{','}` |

The two `semantic/` cases came with the corpus when it was repinned to jRegTab 0.5.1
(pyRegTab 0.5.1): their `pattern.rtl` files are the only ones in the set containing
an actual `<ANCH(n)>` setting and a delimited specification `{','}`.
`conformance/VERSION` itself did not change, so the block above remains current.

Snapshots (`*.snap`) are generated by `npm run test:grammar:update`; snapshot diffs
must be reviewed as part of any PR that changes tmLanguage.
